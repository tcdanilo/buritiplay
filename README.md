# Buriti Play

Site do estúdio Buriti Play, publicado pelo GitHub Pages em https://tcdanilo.github.io/buritiplay/.

- `privacy.html`, `privacidade.html`, `privacidad.html`: política de privacidade do Sniff & Sort (inglês, português e espanhol), o endereço que vai na App Store.
- `support.html`: página de suporte (os três idiomas).
- `index.html`: página do estúdio.

As páginas são geradas por `python tools/site-gen.py .` (os textos ficam no próprio script).
